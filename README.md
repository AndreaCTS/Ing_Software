# Ing_Software
Aplicativo Web que funciona como una red social en donde las personas pueden compartir información con respecto a la seguridad de la ciudad de Bogotá, reportes de la ubicación de zonas peligrosas en la ciudad, pedir el servicio de un wheel compartido con varias personas y finalmente ver en un mapa cuales areás de la ciudad son las que más presentan reportes de robos o acciones delectivas. 

Para iniciar proyecto de front: 
-npm i
-npm start

Para iniciar el proyecto desde el backend:
-crear una base de datos llamada fullstack en mysql
-configurar los credenciales en application properties
-correr el archivo de fullstackBackendApplication
